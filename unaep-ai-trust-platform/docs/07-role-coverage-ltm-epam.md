# LTM and EPAM role-coverage objective

## Objective

This reference implementation was extended to close the previously identified hands-on gaps for the LTM AI Strategy / Enterprise Architecture and EPAM AI Solution Architecture / AI-native delivery role families.

## Capabilities intentionally covered

- enterprise AI architecture;
- Microsoft Foundry / Agent Framework;
- Azure-first cloud-native deployment;
- RAG / Azure AI Search;
- agentic tools;
- Copilot-oriented SDLC instructions and CI;
- FastAPI/contracts;
- Docker/Kubernetes;
- CI/CD;
- integration patterns;
- AI governance and security;
- MLOps/LLMOps evaluation;
- observability;
- AI red teaming;
- MCP;
- A2A;
- developer-productivity measurement;
- CRM controlled-write workflow.

## Explicitly deferred

Only two platform replicas are intentionally deferred:

1. **Google ADK / Vertex AI**
2. **AWS Bedrock / AgentCore**

These are planned as future replicas of the same architecture, preserving the tool contracts, governance gates, observability and evaluation model.

## Accuracy rule

"Implemented" is not equated with "100% verified." A capability reaches 100% only after observed execution evidence satisfies the relevant gate.

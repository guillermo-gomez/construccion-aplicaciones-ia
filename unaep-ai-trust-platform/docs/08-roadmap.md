2. GEval and Jev;

4. Langfuse;
5. DeepTeam;

## Future replicas

### Google
Replicate the same capability model on:
- Google ADK;
- Vertex AI Agent Engine / associated managed runtime;
- equivalent IAM/secrets/observability controls.

### AWS
Replicate on:
- Amazon Bedrock;
- AgentCore / related agent runtime services;
- equivalent IAM/secrets/observability controls.

The design intent is **platform substitution, not governance substitution**: the same evaluation, authorization, traceability and release principles remain mandatory.
